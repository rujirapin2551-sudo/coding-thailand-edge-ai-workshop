## 1. โจทย์ของทีม

**Problem statement** (1-2 ประโยค บอกว่าจะแก้ปัญหาอะไรในชีวิตจริง):

คนทั่วไปมีความเสี่ยงต่อการเกิดอุบัติเหตุจากการล้ม 
หรือเกิดเหตุฉุกเฉินระหว่างการใช้ชีวิตประจำวัน ซึ่งอาจทำให้ได้รับบาดเจ็บและไม่ได้รับความช่วยเหลือทันเวลา
อีกทั้งยังยากต่อการเฝ้าระวังพฤติกรรมการเคลื่อนไหวตลอดเวลา

## 2. Class Definition

ระบุ class ที่จะใช้ + เกณฑ์ที่ทำให้แต่ละ class แตกต่าง:

| # |ชื่อ Class|           คำอธิบาย (3-4 ประโยค)             |        สิ่งที่ทำให้ต่างจาก class อื่น          |
| 1 | normal |         ผู้ใช้ยืนอยู่กับที่หรือขยับเล็กน้อย            |      distance คงที่ และ motion ต่ำ        |
| 2 | moving | ผู้ใช้มีการเคลื่อนไหวต่อเนื่องและเปลี่ยนตำแหน่งตลอดเวลา |   motion สูง และ distance เปลี่ยนต่อเนื่อง   |
| 3 | danger |         ผู้ใช้ล้มลงอย่างรวดเร็วและนอนนิ่ง           | distance เปลี่ยนฉับพลัน และ motion สูงช่วงสั้น |


---

## 3. Edge Cases — สิ่งที่อาจสับสน

ระบุสถานการณ์ที่อาจทำให้โมเดลสับสน:

1. นั่งลงเร็ว ๆ อาจถูกจัดเป็น “ล้ม”
2. เดินช้า ๆ อาจถูกจัดเป็น “ยืน”

**วางแผนแก้:**

  ใช้ข้อมูลจากทั้ง Motion Sensor และ Distance Sensor ร่วมกัน
เพิ่มเวลาตรวจสอบก่อนสรุปผล เช่น หากยังมีการเคลื่อนไหวต่อเนื่องจะไม่ถือว่าล้ม
เก็บข้อมูลหลายรูปแบบเพื่อให้โมเดลเรียนรู้พฤติกรรมที่แตกต่างกัน

## 5. Diversity Plan — กันอคติ (Bias)

ตอบ 3 คำถาม:

### a) มีหลาย "environment" ไหม?

เก็บข้อมูลทั้งในพื้นที่เรียบ บรรได และทางเดิน

### b) มีหลาย "subject" ไหม? (กรณี Vision/Audio/Motion)

เก็บข้อมูลจากสมาชิกหลายคนในทีม
มีความสูงและลักษณะการเคลื่อนไหวแตกต่างกัน

### c) มีหลาย "variation" ไหม?

มีทั้งเดินเร็ว เดินช้า นั่งเร็ว นั่งช้า และล้มหลายรูปแบบ
รวมถึงเก็บข้อมูลในระยะที่ต่างกัน
