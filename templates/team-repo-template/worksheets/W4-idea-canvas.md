## 🎯 1. Problem & User

### a) เราจะแก้ปัญหาอะไร?

  บริเวณชายหาดและทะเลมักมีปัญหาขยะจำนวนมาก ส่งผลต่อสิ่งแวดล้อม 
ภาพลักษณ์การท่องเที่ยว และรายได้ของชุมชน การเก็บขยะด้วยแรงคนเพียงอย่างเดียว
อาจไม่สามารถกระตุ้นให้คนมีส่วนร่วมได้อย่างต่อเนื่อง

### b) ใครคือ user หลัก?

- นักท่องเที่ยว
- ชุมชนและพ่อค้าแม่ค้าริมชายหาด
- หน่วยงานดูแลแหล่งท่องเที่ยว

### c) ทำไม Edge AI ถึงเหมาะกับปัญหานี้? (ทำไมไม่ใช่ Cloud)

  Edge AI สามารถตรวจจับปริมาณขยะจากกล้องได้แบบ real-time 
บนอุปกรณ์ทันที ทำให้ระบบตอบสนองรวดเร็ว เปิดเกมได้อัตโนมัติ 
และไม่จำเป็นต้องส่งข้อมูลขึ้น Cloud ตลอดเวลา

## 💡 Tips สำหรับช่วงต่อยอด

1. **ถ้าต้องอธิบายงาน 2 นาที ทีมควรแบ่งช่วงพูดกันล่วงหน้า**
2. **ถ้าต้องโชว์สด ควรมีแผนสำรองเมื่อ internet หรือ hardware มีปัญหา**
3. **Document ทุก iteration** ใน GitHub — commit ทุก hour
4. **Token = constraint ที่สอนการตัดสินใจ** — เลือกสิ่งจำเป็น
5. **ไอเดียดี + execute ไม่จบ < ไอเดียเรียบง่าย + execute เสร็จ**
