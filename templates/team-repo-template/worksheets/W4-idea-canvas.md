## 🎯 1. Problem & User

### a) เราจะแก้ปัญหาอะไร?

  ในการผลิตหรือจำหน่ายขนมปัง อาจเกิดปัญหาขนมปังขึ้นรา ไหม้ หรืออบไม่สุก 
ซึ่งส่งผลต่อคุณภาพสินค้าและความปลอดภัยของผู้บริโภค การตรวจสอบด้วยสายตามนุษย์อาจผิดพลาดหรือใช้เวลานาน 
โดยเฉพาะเมื่อมีจำนวนสินค้ามาก```

### b) ใครคือ user หลัก?

- ร้านเบเกอรี่ขนาดใหญ่
- โรงงานผลิตขนมปัง
- พนักงานตรวจสอบคุณภาพสินค้า (QC)

### c) ทำไม Edge AI ถึงเหมาะกับปัญหานี้? (ทำไมไม่ใช่ Cloud)

  Edge AI สามารถประมวลผลภาพได้ทันทีบนอุปกรณ์ 
ทำให้ตรวจสอบคุณภาพขนมปังได้แบบ real-time โดยไม่ต้องส่งภาพขึ้น Cloud 
ลดเวลาในการตอบสนองและช่วยรักษาความเป็นส่วนตัวของข้อมูลการผลิต

## 💡 Tips สำหรับช่วงต่อยอด

1. **ถ้าต้องอธิบายงาน 2 นาที ทีมควรแบ่งช่วงพูดกันล่วงหน้า**
2. **ถ้าต้องโชว์สด ควรมีแผนสำรองเมื่อ internet หรือ hardware มีปัญหา**
3. **Document ทุก iteration** ใน GitHub — commit ทุก hour
4. **Token = constraint ที่สอนการตัดสินใจ** — เลือกสิ่งจำเป็น
5. **ไอเดียดี + execute ไม่จบ < ไอเดียเรียบง่าย + execute เสร็จ**
